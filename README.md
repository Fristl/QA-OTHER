# QA-OTHER

## Что делает скрипт

- Принимает путь к одному лог-файлу или к директории с логами.
- Считает общее количество запросов.
- Считает количество запросов по HTTP-методам: `GET`, `POST`, `PUT`, `DELETE`, `OPTIONS`, `HEAD`.
- Формирует топ-3 IP-адресов по количеству запросов.
- Формирует топ-3 самых долгих запросов (метод, URL, IP, длительность, дата).
- Сохраняет отдельный JSON-отчет для каждого проанализированного лог-файла.
- Выводит такую же JSON-статистику в терминал.

## Использование

```bash
python3 access_log_report.py PATH [--pattern "*.log"] [--recursive] [--out "./"]
```

### Примеры

Анализ одного файла:

```bash
python3 access_log_report.py ./access.log
```

Анализ всех `.log` файлов в директории:

```bash
python3 access_log_report.py ./logs --pattern "*.log"
```

Рекурсивный анализ логов и сохранение отчетов в `./reports`:

```bash
python3 access_log_report.py ./logs --recursive --out ./reports
```

## Результат

Для каждого проанализированного файла скрипт:

1. Печатает JSON-статистику в терминал.
2. Сохраняет JSON-отчет в директорию вывода в формате:

`<имя-файла-источника>-<timestamp>-scan.json`
